# HeadFoundry：需求、目标、物料、技术与失败路线交接

整理日期：2026-10-14，Asia/Shanghai。代码证据基线为
`93fa964908bdb936995d4408bc7090c6c878a7ba`，`main` 与 `origin/main` 同步。

其内容予以保留，不把未提交记录伪称为已发布代码。

## 1. 一句话结论

目标是独立开发可商用、多视角、可编辑的完整头部重建产品，尽量接近
KeenTools 的可见质量，而不是仅复现一个模型接口。目前已建立可运行的
权利校验、相机与几何诊断、真实 OBJ/Blender 白模对比和实验追溯链；
**尚未得到通过完整视觉验收的可辨识头模，也未证实 KeenTools 水准**。
当前优先只还原头模，头发与纹理暂停。

## 2. 原始需求与后续变化

### 原始委托：Milestone 1 纵向切片

1. 唯一允许修改的项目仓库是 `C:/workspace/headfoundry`；开始工作先核对
   cwd、Git 状态，保留已有改动。不得读取、复制或修改 Peek 实现，亦不得使用
   KeenTools 私有会话、服务或生成输出做逆向或竞争性黑盒基准。

   访问受限时先完成本地接口、确定性 fixture 和安装入口；禁止回退到非商业权重。

   相机初始化为唯一主要变量，正式几何/纹理在其后。
7. 运行测试、记录结果、更新 README/研究/ADR，形成独立 Git commit。

## 3. 最终产品目标与验收缺口

完整目标不是当前白模实验：推荐输入5–10张清晰、中性、同一对象的正面、斜侧、
双侧近纯侧照片；输出可编辑、稳定拓扑完整头部，覆盖颅顶、双侧、耳和颈部过渡，
提供每视角相机，先交付 OBJ/GLB。粗身份几何通过后再做细节、4K UV纹理、眼/牙、
表情与 ARKit 兼容 blendshape；用户当前的头模优先不等于永久删除这些产品目标。

研究报告中的1–3分钟优化预算和24GB以上生产GPU是规划估计，并无当前达标证据。
没有完成生产服务、性能SLA、发布包、商业部署或盲测质量对标。

验收必须覆盖：合法输入及资产、真实相机、完整几何/拓扑、固定白模多视角、
受保护正面与双侧、必要的独立留出照片/合法扫描真值、再到纹理与完整重建。
研究报告提出至少20个获同意对象的先导基准；该基准尚未完成，20也不是充分
人口覆盖证明。对 KeenTools 的描述只来自公开文档，不是本项目已达到其质量的证据。

| 状态 | 正确含义 |
|---|---|
| `TECHNICAL_CHECK_PASSED` | 有边界的工程检查通过，不等于视觉通过 |
| `UNVERIFIED` | 所需证据尚未取得 |
| `REJECT` | 必需门禁失败或缺失，不能提升默认结果 |
| `PARTIAL_SUCCESS` | 局部/数值进展，缺完整合法视觉证据 |
| `ACCEPT` | 所有受保护门禁及完整独立视觉证据通过 |

## 5. 技术框架：已有实现与未来设想分开

### 已有代码与本地链路

最小Python包，`pyproject.toml` 要求Python≥3.11、NumPy≥2,<3；
几何可选依赖SciPy≥1.14,<2。无无关UI或服务端脚手架。

| 层 | 位置/职责 |
|---|---|
| 权利与输入 | `manifest.py`、`inputs.py`；文件完整性、许可/用途/同意与输入报告 |
| 相机 | `camera.py`、`vggt.py`、`da3.py`、`dense_camera.py`、`bundle.py`、`tracks.py`、`epipolar.py` |
| 几何 | `flame.py`、`target_asset.py`、`target_fit.py`、`template_pose.py`、`profile_fit.py`、`subdivision.py`等 |
| 可见性与表面 | `raster.py`、`surface_diagnostic.py`、`depth_surface.py`、`mesh_section.py`、`contact.py`等 |
| 融合与门禁 | `fusion.py`等基础工具，`quality.py`统一拒绝/通过契约；存在模块不等于完成生产融合 |
| 回归与可追溯 | `tests/`确定性及反例；`examples/`锁；`docs/`实验、ADR、ledger |
| 本地真实证据 | 忽略目录 `assets/private/` 内的输入、脚本、OBJ/NPZ、审计、固定Blender场景和对比图 |

相机适配契约为OpenCV camera-from-world：x右、y下、z前，外参3×4、内参
像素K为3×3。归一化DLT是已知3D/2D对应的参考，不是自动照片初始化。
工程门禁含刚性旋转、焦距/主点、跨视角焦距、正深度与p95投影。
相机与OBJ/Blender另有坐标转换，必须按具体导出记录核对，不凭左右文件名猜轴。

近期全头实验使用有来源的GNM中性数据、相同闭合算子作用于均值与basis，
30维身份、冻结姿态/相机、两次有限Catmull-Clark细分；拟合实际可见的轮廓/
眼开口/外唇外观，检查真实导出OBJ上的位移、面积、法向和first-hit。
这不是已经训练出的自有端到端头部模型。

### 尚未作为完整产品交付的目标架构

输入验证 → 相机/点图初始化与稳健优化 → 共享身份粗头模 → canonical UV/vertex
置信融合 → 拓扑约束的逐对象细化 → 源颜色校准/可见性纹理融合 → 验收与OBJ/GLB导出。
“canonical融合、生产4K纹理、表情/完整眼牙、稳定端到端”属于后续设计和门禁，
不能因目录中有基础模块就称其已完成。

## 6. 已尝试且应记住的失败路线

这里的“拒绝”指测试过的具体方案，不是证明整个算法领域不可行。
原因不充分时标未知，不把相关性写成根因。保留原始失败产物，禁止改门槛换通过。

| 路线 / 实验 | 观测事实 | 应保留的结论与停止条件 |
|---|---|---|
| 商业VGGT访问依赖，0002及后续 | 接口/fixture通过；真实商业checkpoint没有可用本地哈希 | 不等待它阻塞全部研究，也不换非商业权重；保留精确接口，替代另立身份 |
| 匹配器/自由点相机，0015–0018、0167–0169、0185 | LighterGlue联合拟合 held p95约7.5456px；DA3约7.5485px；当前相机轨迹审计7.374px，目标3px；人工点定位不确定性大 | 低Sampson/检测器自洽不是共同物理相机；独立生成输入更不能当真实标定集 |
| SIFT/稀疏重建，0105 | 标准无有效pair；仿射候选仅一对，侧面不连通，未恢复稀疏模型 | 不把局部匹配成功叫SfM成功；需正确多视图物料/对应 |
| 密集预测直接融合，0106–0108 | Apache MapAnything推理完成；相机p95约48.58px；own-view相机/ray不完全一致，跨视角仍有片状面 | 坐标转换通过不保证相机模型一致；准确unprojection也没救该密集场，停止直接融合这次输出 |
| 通用图形target与局部深度场，0055起、0117–0141等 | 局部轮廓常能降误差，但嘴/眼/鼻仍通用；单侧改善、另一侧或正面退化；多次守门后选零/不可见步长 | 不再重复单个嘴唇振幅、RBF、前相机ray标量扫描；要求新的连贯解剖表达和可见证据 |
| 自由点与均值保护，0121–0128 | 自由相机不能转移到实际头面；保护均值仍可能让单个眼点5.42→10.30px | 拟合真实表面，逐点保护；均值、自由点和真实导出网格不是同一对象 |
| 平滑/局部闭嘴补丁，0111–0116、0124–0125 | 减少刻面/边界角度不恢复身份；mouthClose源有采样相交，单调gap也不保证最终网格无碰撞 | 控制笼/平滑法向/细分面不同；用最终面验证。自然闭合、拓扑正确与碰撞自由分开 |
| FLAME线性身份与拓扑转移，0142–0143 | 模型转换通过；测试结果通用、侧面差，最佳转移双侧均值约32.22/30.42px | 拒绝测试过的拟合/转移，不否定FLAME许可或所有3DMM；不能以合法大basis代替身份结果 |
| 先加外观来补几何，0174–0175 | 局部Gaussian/源颜色提高拟合视图外观；排除颜色拟合的侧面依旧差，旧几何已看过该图 | 外观部分成功，不是独立重建泛化，也不能隐藏错白模；当前暂停纹理 |

### 跨路线的真实工程教训

- 可见性必须first-hit检查完整导出面；front-facing、正深度、旧材料绑定都不够。
- 真实轮廓是视角相关边界，不是固定3D材料轨迹；颜料边不是几何唇体边界。
- 闭合算子须同时作用于均值及形变basis；RMS位移保护不能替代逐点硬界限。
- 控制笼安全不保证两次细分/最终OBJ安全；必须读实际序列化文件独立回放。
- 所有拟合/选择已见过的视图都不应改名“独立留出”；交错像素行也不是新对象泛化。
- 0207审计另修正旧独立报告中用稠密行切片冒充真实训练/评价行的问题；新审计按
  实际行索引查找。0206公开的稠密全行结论仍是不同且有效的那项统计。
- mandatory权利门禁不能使用优化运行会禁用的Python assertion充当生产拒绝机制。
- 失效optimizer的success=false、终端参数、完整守门和未完成视觉复核都须原样报告。
