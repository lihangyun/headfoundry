## Findings and next decision

1. DSO's published factor graph attaches each inverse-depth point to its own
   host frame and only the target frames in which it is observed. It does NOT
   require one complete track through every frame. However its released entry
   still calls setGlobalCalib before initialization,expects geometric correction
   and warns that initialization is unreliable. Jointly refining intrinsics is
   not evidence of calibration-free initialization. Do not install the GPL3
   implementation as if it solves missingK;independent windowed-method research
   remains possible,not a registered retry of0321's partial34tracks.
2. DepthPro remains legally eligible for free-commercial evaluation,but its
   current source still requires a full depth/FOV feature graph and numpy<2.
   That repeats0312's identified isolated-runtime cost rather than supplying a
   new small initializer. Defer,not a measured hardware/accuracy rejection.
3. FLARE's official license is CC-BY-NC-SA4.0. REJECT adoption under the user's
   commercial-use constraint;no weight or framework is downloaded.
4. Prefer a separately bounded AnyCalib entry audit. Its FoV/ray representation
   addresses missing single-image calibration cues,not LKcomplete-track count.
   Source explicitly separates inference from GeoCalib-derived siclibtraining/
   evaluation code;the latter is not downloaded/installed/reintroduced. This is
   neither a new actual camera solution nor proof that the real video is cropped.
