## Four bounded candidates

1. DroidCalib:official code offers target-free video intrinsic calibration and
   an AGPL-3.0 grant,not a noncommercial prohibition. Integrating it would require
   checking/meeting source-distribution obligations rather than silently changing
   HeadFoundry licensing. Its reference demo specifies12GBGPU and CUDAextension
   compilation;local hardware probe finds RTX3070/8192MiB. Smaller execution might
   be possible but is untested,not an8GBfailure measurement. Archived/unmaintained
   reference and old dependency stack increase porting cost. Defer this complete
   integration;do not install on a claim that current hardware is cleared.
2. MegaSaM:top-level Apache2code does not clear its default full pipeline. The
   official demo invokes UniDepth in addition to DepthAnything;UniDepth explicitly
   publishes BY-NC4.0. REJECT the stock dependency recipe under this project's
   free-commercial rule. A separately licensed replacement would be a distinct
   method requiring a new protocol,not permission to revive deleted MoGe/DA3.
3. DepthPro:official README explicitly grants its code AND released weights
   under the repository's permissive Apple terms. Do not wrongly call it NC.
   It exposes a focal estimate,but the released FOV head depends on the shared
   low-resolution decoder features as well as its own encoder;the published
   extraction cannot simply be called as a tiny standalone focal classifier.
   Its declared numpy<2conflicts with the current2.5.2environment;an isolated
   runtime and full state/import/byte/resource audit would be needed. Weight
   digest,size/local peak and actual accuracy not verified here. Defer larger
   full-graph admission,not reject its licensing or claim a known memory failure.
4. GeoCalib:0260already verified Apache2code/CC-BY4weights and explicitly excluded
   standalone SE3claims.0311now motivates a different,limited role:an additional
   learned focal PRIOR only,not head-relative camera pose or certified capture K.
   Pinned source supports CPU,explicit covariance/uncertainties and local checkpoint
   paths;published pinhole asset is116074121bytes per0260metadata. Prefer a small
   separately bounded software/known-truth entry audit over the larger stacks.
   No install is cleared yet:release-byte identity,complete executed imports and
   strict full-state conformance are still required. Upstream flexible_load must
   not silently admit missing/random parameters. No automatic download/fallback
   or falsely treating a default zero uncertainty as a calibrated confidence.

The learned-prior role is an inference about usefulness,not source evidence of
2%focal/2mmhead performance. Model-reported covariance cannot certify true error
on a close-up person/blue-wall scene. An independent known-camera fixture and
crop/resize conventions must pass before any actual-video camera experiment.
