## DSOis not a solved-calibration claim or a disguised0251retry

Paper formulation directly couples camera motion with inverse depths anchored
in observed image patches,rather than requiring semantic detector points or
known scan geometry. This is a different candidate observation mechanism from
0251'sfixed supplied-surface/unconstrained9-term SHcamera refinement. It does
not justify restoring that runner,clamping negative SHor using medical geometry
as inference input. Any prototype must be independently written from published
math,not copy restricted model implementations or import an unreviewed stack.

Counter-evidence is explicit in the official README:geometric calibration is
an input,initialization is reported unreliable,and rolling shutter/geometric
miscalibration/photometric effects can harm direct tracking. Sparse photometric
geometry/motion estimation is NOT proof it can recover our unknown intrinsics,
head rotations or skin correspondences. No unobserved camera device/readout or
photometric response is assumed known. Paper benchmark quality is not face-mm
evidence. GPL3copyleft is not an NCterm,but obligations still need review before
shipping third-party code;no binary is integrated by this screen.
