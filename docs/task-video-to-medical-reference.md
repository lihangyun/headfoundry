## 研发与验证闭环

真实视频抽帧与质量/表情/遮挡检查 → 视频内物理对应与相机估计 → 重建候选网格
→ 固定配准和区域的医学皮肤误差评价 → 对算法作有依据的单变量改进。

帧和验证范围应在看到候选误差前确定。不要用误差挑选好看的帧、点或区域。
头部转动、表情和颈部运动不能未经验证都当作同一刚体；相机、几何、表情、
坐标约定的问题需要分开诊断。医学几何仍隔离于重建器，不将逐点扫描目标
直接拉回候选网格以伪装成视频恢复。病例开发评价不能替代保留病例验证。

允许采用已核实免费可商用的第三方实现/模型及独立算法。优先已有基础库，
不因单条路线失败而自动要求付费模型、训练或改变输入资料。不读取 Peek 实现，
不使用 KeenTools 私有服务或输出，不恢复已退役集成来反复扫参数。

## 2026-10-26：自主方案的持续研发方式

用户明确要求：学习各家已验证的长处、查明失败原因、补足短板，形成自主重建
算法与系统，而不是持续更换模型。最终交付和上述全部验收标准不变；本节不是
把目标缩小为文档、测试或合成场景。现有长期目标继续使用，不重复建立目标。

1. 先维护[失败归因与能力台账](failure-capability-ledger.md)。每项分开记录失败
   所在阶段、直接证据、已证实机制、未解决假设、可复用能力和适用边界。
   “没通过门禁”不是根因；许可不允许、没有运行、初始化停止、精度不合格和
   用户视觉拒绝不能混为一谈。文档记录复核与原始数值独立复核也须区分。
2. 对关键未知原因优先进行有判别力的有界诊断，不为了完善台账重跑全部历史
   实验。已有失败集成不自动恢复；必要重放仍须符合实质新假设和预登记要求。
3. 组合方案必须说明各组件提供什么独立信息、补哪项已知短板，并通过固定
   输入和对照/消融验证其贡献。不得把多个相关偏差简单平均后称为准确。
4. 候选对应、可见性评分、相机拟合残差和独立几何证据分开。低拟合残差不能
   自证标定准确；形状/法线先验不能冒充视频测得的个体几何。
5. 清理失败专属集成前必须记录可复用部分及其依据。保护成功夹具和通用工具，
   但不能仅凭“也许以后有用”无限保留权重和环境。恢复点不等于自动重跑许可。
6. 自建方案当前指自主算法和系统；没有新增使用人体资料训练神经网络的授权。
   任何新的模型训练计划需另行明确数据权利、用途、成本和验收，不隐式启动。
